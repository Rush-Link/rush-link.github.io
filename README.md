# RushLink

This public repository hosts the [RushLink website](https://rush-link.github.io/) and its downloadable desktop releases.

RushLink is a free companion app for HeadRush Prime, Flex Prime and Core. Its flagship TonePilot and StageHand workspaces make tone auditioning, rig management and live control easier away from the pedal screen.

## Early alpha

RushLink is under active development. Back up important rigs before using an early build. Current Windows installers are unsigned, so Windows SmartScreen may display a warning.

## Download

Get the latest public build from [GitHub Releases](https://github.com/rush-link/rush-link.github.io/releases). Installer binaries belong in Releases and are not committed to this repository.

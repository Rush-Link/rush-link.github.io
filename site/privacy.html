Privacy, kept clear.

RushLink by Cygma Audio does not include analytics, advertising SDKs or crash-reporting telemetry. Application data stays local; contact-form data is sent only when you choose to submit an enquiry.

Application data

Preferences, StageHand layouts, favourites, Test Rig templates, cached catalogue data and rig history stay in the local RushLink application profile on your computer. They are not included in installers or sent to Cygma Audio.

HeadRush connection

RushLink communicates with the HeadRush device you select over your local network. Tone3000 and HeadRush Cloud requests use capabilities exposed by that connected device.

Website enquiries

The homepage and Hire Me contact forms send the name, reply email, selected topic, message and consent value you provide to Formspree so the enquiry can be delivered and answered. Formspree processes that submission under its own privacy terms. Nothing is sent until you press “Send enquiry”.

Files and release totals

Your website colour-mode choice is stored only in this browser. Backups are read or written only after you select a local file. The marketing site requests public GitHub Release metadata to show release and download totals; GitHub processes those web requests under its own terms.
